最后，我会贴上小冰糖所有的动作。对于我来说，我很喜欢它玩小球还有忙碌时敲键盘的样子。如果你也觉得冰糖可爱的话，可以直接下载我的这份代码，将它放在你的codex宠物文件夹下就可以使用啦！


codex宠物文件夹的地址在"C:\Users\你本人的用户\.codex\pets"，将下载下来的代码拖动到这里，刷新codex宠物即可获得一只可爱小猫桌宠！


如果没有GPT plus，也可以通过cc switch搭桥连接各种API中转进入codex，一样可以将小冰糖作为你的桌面宠物！
